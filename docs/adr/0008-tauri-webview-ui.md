# The desktop app's UI is a Tauri webview, and secrets cross into it only when shown

The desktop app moved from GPUI to Tauri 2: a WebKitGTK (Linux) or WebView2 (Windows) window showing a React UI, over the same `core` and `workspace` crates. We chose the Linear-style prototypes' design (one variant per screen, built as HTML in `crates/app/prototype-linear-ui` on the `feat/linear-style-ui-prototypes` branch), and reproducing it faithfully — its type, motion, popovers and dense lists — took web technology; in GPUI each screen meant rebuilding widgets that the browser already has. The cost is a bigger runtime (a system webview) and a second toolchain (Node and pnpm, which the Companion extension already uses).

The Workspace stays in the Rust process, behind a mutex, and remains the only owner of decrypted Vaults. The UI reaches it only through typed commands (`crates/app/src/commands/`, with TypeScript bindings generated by tauri-specta and checked for staleness in CI) and hears of changes through events (`workspace-changed` carries a revision; the UI refetches). Secrets cross the IPC boundary only when the user is shown one: Entry DTOs leave out passwords, protected custom fields and TOTP secrets, and `reveal_*` commands return one value when the UI asks. Copying never goes through the UI: `copy_field` copies from the Workspace to the clipboard and clears it as before. An edit sends only what the user changed (`password: null` keeps the password), so an untouched secret never makes the round trip. Master passwords arrive as strings and are wrapped in `SecretString` at once; what the webview's JavaScript heap held is out of our control, the same compromise ADR 0004 made for text GPUI displayed.

The webview loads nothing remote. The UI and its fonts are bundled into the binary; favicons are downloaded by the Rust side (only once the user turns that on) and served with custom icons through a `kficon:` protocol from memory; the CSP allows scripts only from the app itself and connections only to Tauri's IPC. The window gets no Tauri plugin's JavaScript API: file dialogs and opening Dropbox's page happen in Rust commands, and the capability grants only listening to events and reading the window's theme. Same-user malware stays out of scope (ADR 0004); a page script could only run in this webview if the bundled UI itself were compromised.
